# Nexus icon theme

`Nexus/index.theme` defines a thin icon theme that inherits `breeze-dark` and
overrides only brand icons. SVGs are copied from `branding/icons/nexus-n.svg`
during the package build:

| Installed icon | Purpose |
|----------------|---------|
| `apps/scalable/nexusos.svg` | Kickoff launcher icon, `nexus` CLI launchers |
| `places/scalable/start-here.svg`, `start-here-kde.svg`, `start-here-kde-plasma.svg` | Application launcher |
| `places/scalable/distributor-logo.svg` | About This System / Info Center |

A full custom icon set is out of scope for v0.1.0.
